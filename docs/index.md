# Shukka License

你卖软件，最后总要回答一件事：这把激活码还能不能用，能装几台。Shukka License 把这件事放到你自己的服务器上——你签发密钥、定死席位和期限，软件在运行时来问，得到能用或不能用。用户换设备自己处理，不必每换一台电脑都找你改后台。

一份实例只服务你自己的产品。你继续用现在的方式收款和发货，这里只记住已经发出去的授权，并在运行时执行它。

## 一次授权怎么走完

你在后台建立产品，再签发密钥：能绑几台、会不会过期，当场定死。完整密钥只出现这一次，之后只留哈希，丢了只能作废重发。

用户注册账号，把密钥兑成对某个产品的权益，再绑设备。席位满了就绑不进去；过期、密钥作废或权益停用之后，校验会失败。兑换以后不能改席位或到期日，要改就发一把新的。

软件之后只做两件事：绑设备，以及确认这台已绑定的设备仍然有效。失败时服务会说明原因（密钥不对、席位满了、过期、设备不在授权里），开不开功能由软件自己决定。
