# Agent notes

## Documentation

- **Internal docs** live in `.context/`. Use this directory for development notes, deployment runbooks, validation records, and other material meant for maintainers and agents — not the public site.
- **Public docs** live in `docs/`. This is the source tree for the documentation site generated by Zensical (`zensical.toml`, `just docs` / `just docs-build`, output in `site/`).
- Do not put internal runbooks or investigation notes in `docs/`. Do not treat `.context/` as Zensical page sources.
